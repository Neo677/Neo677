I'm a software-engineering student at **42 Nice**, working across the full depth of
the stack — from memory-tight systems code in **C and C++**, to **machine-learning**
projects in Python, to **full-stack web** applications. I care about correctness,
clean abstractions, and tooling that gets out of the way.
